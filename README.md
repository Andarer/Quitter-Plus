> **Quitter Plus** — это современное приложение для преодоления зависимостей, отказа от вредных привычек и внедрения поддерживающих полезных ритуалов. Разработано на базе концепции [brandonp2412/Quitter](https://github.com/brandonp2412/Quitter) с глубоким расширением возможностей: настраиваемые виджеты, трекинг полезных привычек, система достижений с наградами, антикризисный режим **Urge Surfing** и облачная синхронизация между устройствами.

* **Android 5.0 Lollipop (API Level 21) и новее** (вплоть до Android 14+).

* Возможность использования как **Progressive Web App (PWA)** в браузере или автономно на iOS/Desktop.

## ✨ Ключевые возможности

### 1. ⏱ Точный счетчик трезвости в реальном времени
* Секундный таймер свободы от старта без перезагрузки интерфейса.
* Калькулятор сбережений: подсчет сэкономленных денег, непотребленных единиц (сигарет, стиков, порций, сессий ставок) и спасенных часов жизни.
* Шкала биологической регенерации: 11 научных этапов восстановления (20 минут, 8 часов, 24 часа, 48 часов, 72 часа, 1 неделя, 2 недели, 1 месяц, 3 месяца, 6 месяцев, 1 год).
* Поддержка нескольких трекеров параллельно (курение, вейп, алкоголь, сахар, кофеин, гемблинг, соцсети или свои цели).

### 2. 📋 Трекер полезных привычек
* Замещение пустоты после отказа полезными активностями (медитация, вода, спорт, чтение, сон).
* Интерактивная 7-дневная сетка выполнения, текущая серия (streak) и личный рекорд.
* Виджет на главном экране для отметки привычек за сегодня в один клик.

### 3. 🧩 Интерактивные виджеты дашборда
* Модульные карточки рабочего стола: Живой таймер, Краткая статистика, SOS Urge Surfing, Чеклист привычек, Веха здоровья, Цитата стоиков, Пульс тяги, 30-дневная тепловая карта.
* Меню настроек для отключения и включения любых виджетов.

### 4. 🌊 Экстренный режим Urge Surfing (SOS тяга)
* Научно обоснованная методика д-ра Алана Марлатта: серфинг по волне тяги вместо подавления.
* Дыхательный тренажер 4-4-4 (вдох, задержка, выдох, пауза) с пульсирующей сферой.
* Автономный генератор шума океанской волны через **Web Audio API** (без сторонних MP3).
* Сенсорное заземление 5-4-3-2-1 и экспресс-тест **H.A.L.T.** (Hungry, Angry, Lonely, Tired).

### 5. 🏆 Система достижений и наград
* 16 наград с 5 уровнями редкости (Бронза, Серебро, Золото, Платина, Алмаз).
* Награды за длительность серии, укрощение приступов тяги, экономию средств, выполнение полезных привычек и сеансы осознанности.
* Анимация конфетти и звуковой фанфарный аккорд при взятии новой вехи.

### 6. ☁️ Облачная синхронизация и Local-First
* Работает 100% автономно и офлайн без регистрации.
* Уникальный 6-значный ключ синхронизации (`QP-XXXXXX`) для мгновенного объединения данных между телефоном, планшетом и ПК.
* Полный экспорт и импорт базы данных в формате `.json`.
* Экспорт логов тяги и привычек в `.csv` для анализа в таблицах Excel/Google Sheets.

### 7. 🎨 Темы оформления
* **Dark Slate** — сбалансированная темная тема.
* **OLED Pure Black** — чистый черный для максимального энергосбережения на AMOLED-экранах.
* **Clean Light** — светлая редакторская тема.
* **Emerald Forest** — тема исцеления и природы.
* **Cyberpunk Neon** — технологичный неоновый стиль.
* **Sunset Warm** — теплые янтарные тона.

## 🤖 Автоматизация GitHub CI/CD & Сборка Релизов

В репозитории настроены готовые рабочие процессы GitHub Actions (`.github/workflows/`):

| Пайплайн | Файл | Триггер | Описание |
|---|---|---|---|
| **Build & Release APK** | [`.github/workflows/release-apk.yml`](.github/workflows/release-apk.yml) | Push тега `v*.*.*` или кнопка `workflow_dispatch` | Компилирует приложение на Ubuntu, запускает Capacitor Android, собирает APK для **Android 5.0+** (`minSdkVersion 21`) и прикрепляет файл к GitHub Releases |
| **Auto Changelog** | [`.github/workflows/auto-changelog.yml`](.github/workflows/auto-changelog.yml) | Создание релиза или ручной запуск | Автоматически генерирует `CHANGELOG.md` на основе коммитов по стандарту Conventional Commits |
| **CI Pipeline** | [`.github/workflows/ci.yml`](.github/workflows/ci.yml) | Push / PR в ветку `main` | Проверка TypeScript (`tsc --noEmit`), линтинг и тестовая сборка |

### Как выпустить новый релиз с готовым APK:
```bash
# 1. Зафиксируйте изменения коммитом по стандарту conventional commits:
git commit -m "feat(habits): add custom reminder sound"

# 2. Создайте тег новой версии:
git tag v1.3.0

# 3. Отправьте тег на GitHub:
git push origin v1.3.0
```
После этого GitHub Actions автоматически:
1. Запустит сборку web-дистрибутива.
2. Инициализирует нативный проект Android с `minSdkVersion 21`.
3. Соберет оптимизированный APK через Gradle.
4. Создаст новый Release на странице репозитория и прикрепит туда файл `QuitterPlus-v1.3.0-android5.0+.apk`.

## 🛠 Локальная разработка и сборка

### Требования:
* Node.js 20+
* npm или bun
* Android Studio / SDK (только для локальной сборки APK, на GitHub всё собирается автоматически в облаке)

### Установка зависимостей:
```bash
npm install
```

### Запуск в режиме разработки:
```bash
npm run dev
```
Откройте в браузере `http://localhost:3000`.

### Сборка веб-версии:
```bash
npm run build
```

### Локальная генерация Android-проекта:
```bash
npx cap sync android
npx cap open android
```
