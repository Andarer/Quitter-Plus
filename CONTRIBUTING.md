# Руководство по участию в разработке (Contributing)

Мы приветствуем ваш вклад в развитие **Quitter Plus (by Andárer)**!

## Как предложить изменения:
1. Создайте форк репозитория.
2. Создайте ветку для вашей фичи: `git checkout -b feat/my-new-feature`
3. Убедитесь, что код компилируется и проходит проверку типов: `npm run lint` и `npm run build`
4. Оформите коммиты по стандарту Conventional Commits:
   - `feat(scope): описание новой функции`
   - `fix(scope): исправление ошибки`
   - `perf(scope): улучшение производительности`
   - `docs(scope): изменения документации`
   - `ci(scope): изменения в GitHub Actions`
5. Отправьте Pull Request в ветку `main`.

## Требования к коду:
* Поддержка Android 5.0+ (API 21+) для мобильных сборок.
* Принцип Local-First: приложение должно работать полностью автономно без постоянного интернет-соединения.
* Никаких тяжелых внешних аудио-библиотек: звуки генерируются через Web Audio API.
* Полная типизация TypeScript без `any`.
